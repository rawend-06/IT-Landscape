Docker

Wat is docker en waarvoor word het gebruikt.

Docker is een platform dat IT’ers vaak gebruiken om software die ze hebben ontwikkeld in containers te plaatsen. Doordat de software in een container zit, kun je deze overal uitvoeren en blijft het altijd hetzelfde, ongeacht het systeem of de omgeving. Het is snel, eenvoudig en zorgt ervoor dat applicaties consistent draaien op elke machine.

Installatie Docker

als u Docker wilt installeren, kunt u hieronder een uitgebreide stappenplan vinden om het te installeren.

  1. Ga naar de officiële Docker-website: https://www.docker.com/products/docker-desktop
  2. klik dan op "Download Docker Desktop"
  3. Als u dat hebt gedaan kiest u voor het juiste besturingssysteem.
  4. Als u het hebt geklikt, komt er recht op het scherm een installatieprogramma.
  5. als het installatieprogramma is gedownload, klik het om Docker te installeren.
  6. Dan gaat u een popup zien, waar u de installatie kunt bevestigen daar moet u ja kliken
  7. dan komt er een instalatie scherm, daar staat dan of u wilt dat een icon op uw bureaublad wordt geplaatst. klik erna dan rechts beneden oke
  8. dan word de installatie gestart, dat kan even duren.
  9. als de installatie klaar is, klikt u op "Close"
  10. u kunt erna docker opstarten, als u het hebt opgestart moet u inloggen of registreren.
  11. u bent nu klaar om Docker te gebruiken.

Basis Commando's

  • cd [naam van de directory]: Navigeert naar de opgegeven directory anders kan je niks doen met docker.
  • docker compose up -d: Start alle containers die zijn gedefinieerd in het docker-compose.yml bestand in de achtergrond.
  • docker ps: Toont een lijst van alle actieve containers. Gebruik docker ps -a om ook gestopte containers te zien.
  • docker images: Toont een lijst van alle beschikbare images op je systeem.
  • docker pull: Hiermee download je een image van Docker Hub. Bijvoorbeeld: docker pull python downloadt de Python image.
  • docker rmi [naam van de image]: Verwijdert een specifieke image van je systeem. Bijvoorbeeld: docker rmi python verwijdert de Python image.
  • docker logs [naam van de container]: Toont de logboeken van een specifieke container. Bijvoorbeeld: docker logs my-container.
  • docker --version: Toont de versie van Docker die geïnstalleerd is. Bijvoorbeeld: docker --version.
  • docker compose down -v: Stopt een actieve container. Bijvoorbeeld: docker compose down -v.

dit zijn de basis commando's voor het werken met Docker.

Dockerfile

Een Dockerfile is eigenlijk gewoon mijn eigen recept waarin ik stap voor stap heb opgeschreven hoe mijn applicatie gebouwd moet worden. In dit tekstbestand bepaal ik precies welke omgeving, bestanden en instellingen er nodig zijn.Het fijne hiervan is dat ik niet telkens alles handmatig hoef in te stellen; Docker volgt gewoon mijn lijstje met instructies en bouwt zo elke keer exact dezelfde image. Hierdoor weet ik zeker dat mijn app overal hetzelfde werkt, zonder gedoe.

Docker Compose

Docker Compose is een handig hulpmiddel waarmee ik meerdere containers tegelijk kan beheren. In plaats van elke container apart te starten, kan ik met een enkel commando al mijn services opzetten. Ik schrijf gewoon een docker-compose.yml bestand waarin ik beschrijf welke containers ik nodig heb, hoe ze met elkaar moeten communiceren en welke instellingen ze moeten hebben. Hierdoor kan ik mijn hele applicatie in één keer opstarten, zonder gedoe met losse commando's voor elke container.
