MongoDB

What is MongoDB?

MongoDB is een NoSQL-database die gegevens opslaat in flexibele, JSON-achtige documenten in plaats van in tabellen zoals bij relationele databases. Een belangrijk voordeel is dat je geen vast schema nodig hebt, waardoor je makkelijk data kunt aanpassen en opschalen tijdens de ontwikkeling. Daarnaast is MongoDB goed schaalbaar en kan het grote hoeveelheden data efficiënt verwerken door gegevens te verdelen over meerdere servers.

Praktische toepassingen van MongoDB

  • Web- en mobiele appsom gebruikersdata op te slaan.
  • Real-time datazoals klikgedrag of sensoren analyseren.
  • Opslag van contenten grote hoeveelheden logs.

Installatie

  1. maak in de folder een bestand 'docker-compose.yml' aan
  2. voeg de volgende inhoud toe aan het bestand: 
            version: '3.8'
        services:
        mongodb:
          image: mongo:7.0
          container_name: mongodb
          restart: always
          ports:
            - "27017:27017"
          environment:
            MONGO_INITDB_ROOT_USERNAME: admin
            MONGO_INITDB_ROOT_PASSWORD: geheimwachtwoord
          volumes:
            - mongodb_data:/data/db

        mongo-express:
          image: mongo-express:latest
          container_name: mongo-express
          restart: always
          ports:
            - "8081:8081"
          environment:
            ME_CONFIG_MONGODB_ADMINUSERNAME: admin
            ME_CONFIG_MONGODB_ADMINPASSWORD: geheimwachtwoord
            ME_CONFIG_MONGODB_URL: mongodb://admin:geheimwachtwoord@mongodb:27017/
            ME_CONFIG_BASICAUTH: false
          depends_on:
            - mongodb

          volumes:
            mongodb_data:
  3. start de containers met het commando: docker-compose up -d
  4. open uw browser en navigeer naar http://localhost:8081
  5. type recht vanboven de naam van je nieuwe database ern klik erna op create database

Beheer commandos

  • docker compose up -d - Start de MongoDB en Mongo Express containers.
  • docker compose down - Stop en verwijder de containers.
  • docker volume ls -f - Toon alle volumes.
  • docker exec mongodb mongosh -u admin -p geheimwachtwoord --authenticationDatabase admin - Open een shell in de MongoDB container om direct commando's uit te voeren.
  • docker exec mongo-express bash - Open een shell in de Mongo Express container.
  • show dbs - Toon alle databases.
  • db.gebruikers.insertOne({}) - Voeg een nieuw regel toe aan de 'gebruikers' collectie.
  • db.gebruikers.find() - Toon alle documenten in de 'gebruikers' collectie.

Backup maken

  1. docker exec mongodb mongodump --username admin --password geheimwachtwoord --authenticationDatabase admin --out /data/backupmaakt een database-backup en zet die in een map in de container.
  2. docker cp mongodb:/data/backup ./backup - Kopieer de backup van de container naar je lokale machine.
  3. als je alles opnieuw opstart moet je eigelijk nog steeds je oude gegevens die je in je database had staan kunnen zien, omdat die in een volume staan dat niet verwijderd wordt als je de containers verwijdert.

schaalbaarheid

schaalbaarheid betekent dat je database makkelijk kan meegroeien als je meer data of gebruikers krijgt.

  • Sharding - Verdeling van data over meerdere servers.
  1. pas de docker-compose.yml file aan om de schaalbaarheid te verbeteren. 
          services:
  mongo1:
    image: mongo:7.0
    container_name: mongo1
    command: mongod --replSet rs0 --bind_ip_all
    ports:
      - "27017:27017"
    volumes:
      - mongo1_data:/data/db
  mongo2:
    image: mongo:7.0
    container_name: mongo2
    command: mongod --replSet rs0 --bind_ip_all
    ports:
      - "27018:27017"
    volumes:
      - mongo2_data:/data/db
  mongo3:
    image: mongo:7.0
    container_name: mongo3
    command: mongod --replSet rs0 --bind_ip_all
    ports:
      - "27019:27017"
    volumes:
      - mongo3_data:/data/db
  mongo-express:
    image: mongo-express:latest
    container_name: mongo-express
    restart: always
    ports:
      - "8081:8081"
    environment:
      ME_CONFIG_MONGODB_URL: mongodb://mongo1:27017,mongo2:27017,mongo3:27017/?replicaSet=rs0
      ME_CONFIG_BASICAUTH: false
    depends_on:
      - mongo1
      - mongo2
      - mongo3
volumes:
  mongo1_data:
  mongo2_data:
  mongo3_data:
  2. docker exec -it mongo1 mongosh --eval "rs.initiate()" - Dit comando start de replica set zodat de MongoDB servers samenwerken als één systeem.
