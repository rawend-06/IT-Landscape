CI/CD Pipeline

Wat is een CI/CD Pipeline?

CI/CD (Continuous Integration / Continuous Delivery of Deployment) is een manier van werken waarbij elke codewijziging automatisch wordt gebouwd en gecontroleerd (bijv. testen) via een pipeline. Daarna wordt de software of een artifact zoals een Docker image automatisch geleverd of gedeployed naar een omgeving of registry (zoals GitHub Packages/GHCR). Het doel is sneller, betrouwbaarder en herhaalbaar software opleveren met minder menselijke fouten.

Wat zijn de voordelen ervan?

  • Snellere feedback
  • Minder fouten
  • Betere samenwerking
  • Minder handmatig werk

Hoe moet je een CI/CD Pipeline maken?

  1. je maakt een applicatie
  2. erna maaak je een dockerfile aan
  3. zet de juiste gegevens in de dockerfile
  4. als je dat hebt gedaan moet je een folder .github maken en daarin nog een folder workflows
  5. in de folder workflows maak je een yml bestand aan
  6. in dat yml bestand zet je de juiste gegevens en stappen erin
  7. als dat gedaan is, is het klaar en dan kan je het testen als je naar je repo op git hub gaat en daar naar action gaat moet er een worflow staan met een groene bol
  8. nu elk keer als je een wijziging aanbrengt in je code en die pusht naar github, zal de pipeline automatisch worden uitgevoerd en zal je feedback krijgen over het resultaat van de build en tests.
